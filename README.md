# Temperature Converter

A simple and responsive temperature converter web application built using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius and Fahrenheit in real-time.

# Technologies Used

- HTML5 – for structuring the web page
- CSS3 – for styling and layout
- JavaScript – for dynamic conversion logic

# Features

- Convert between Celsius and Fahrenheit
- Real-time input updates
- Clean and responsive UI
- Error handling for invalid inputs

# How It Works

The website takes a numeric temperature input and a source unit, then calculates and displays the converted values in other units using standard conversion formulas.
